# Security policy

## What is in scope

Please report vulnerabilities that could make DissentKit execute unintended commands, expose private information, alter files outside an expected installation directory, or package files that are not listed in the release manifest.

The installable five-file skill package contains instructions, metadata, references, and license notices. It does not contain executable scripts. The Python scripts in this repository are maintainer tools for validation, evaluation reporting, and package creation.

## Reporting

Use GitHub's private vulnerability reporting option on the repository's **Security** tab when it is available. Include the affected version or commit, reproduction steps, impact, and the smallest safe example.

If private reporting is unavailable, open an issue that asks the maintainer for a private contact route. Do not include exploit details, credentials, private prompts, or other sensitive information in a public issue.

Please allow time for the report to be reproduced and corrected before public disclosure.

## Supported version

Security fixes are applied to the latest release and the default branch. Older releases may not receive backports.
