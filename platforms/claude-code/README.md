# Claude Code adapter

Copy the DissentKit folder to `~/.claude/skills/dissent-kit/` or install it through your preferred skill manager.

Invoke it by name, say `dissent this` for Direct Review, or say `dissent this deeply` for Deliberation.

Subagent availability depends on the host and configuration. DissentKit must label a review `Single-context deliberation` unless it actually dispatches isolated passes.
